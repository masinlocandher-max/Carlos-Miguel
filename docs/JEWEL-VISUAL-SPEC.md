# Jewel public development interface

The public build preserves the WebGL particle renderer, filaments, gold rings, orbitals, scanning, five state transitions, reduced-motion support, live Canvas fallback, collapsible navigation, Focus Mode, responsive shell, and local command routing.

The central object is a neutral mathematical particle sphere, generated by `src/visual/developmentGeometry.ts`. Its coordinates come solely from trigonometric formulas. It uses no photograph, facial landmark, silhouette, portrait texture, identity board, derived likeness file, or network asset request.

## Intentional visual difference

The public development core does not display FMB's face or approved hairstyle. Facial fidelity and visible eye opening/closing cannot be evaluated in this sanitized build. The five state parameters continue to interpolate, but the placeholder communicates attention through light and activity, not facial expression. This placeholder is not a new approved Jewel avatar.

## Interface contract

- Exactly eight sections; navigation hidden by default.
- Drawer dismisses on selection, outside click or Escape and restores keyboard focus.
- Focus Mode hides side panels without shifting the core.
- Command field sits below the core.
- Supported local commands transition through listening, thinking, executing, complete and idle.
- Unsupported provider operations do not claim execution or completion.
- No real API connections, voice capture, authentication, merge or deployment.

## Private asset boundary

Original references, derived geometry, generator scripts containing reference-specific coordinates, and likeness preview screenshots are preserved outside this checkout. Suggested private-only location: a sibling `jewel-private-backup/` directory or separately access-controlled asset storage. Never place them under `public/`, import them into the frontend bundle, or commit them to the public repository.

`.gitignore` excludes the old reference/preview directories, old derived geometry paths, private asset directories, identity-board/likeness patterns and Git bundles. Ignoring a file does not remove historical blobs: this branch was rebuilt from the clean foundation so the former asset-bearing commits are not ancestors.
